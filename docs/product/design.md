# AI 사주 서비스 'Moon Aura' UI/UX 디자인 프롬프트

## 1. 프로젝트 개요

대화형 AI 사주 서비스 'Moon Aura'의 반응형 웹사이트를 디자인해 주세요.

이 서비스는 정확한 사주 계산 엔진과 AI 자연어 해석을 결합하여, 사용자가 자신의 성향과 올해의 운세를 쉽고 편안하게 이해하도록 돕는 서비스입니다.

핵심 콘셉트는 **"신뢰감 있는 정보 구조 + 부드럽고 감성적인 AI 상담 경험"**입니다.

기존의 무속적이고 복잡한 사주 서비스와 차별화하여, 현대적인 자기이해 및 라이프스타일 서비스처럼 디자인해 주세요.

## 2. 디자인 레퍼런스

첨부한 디자인 이미지 2개를 핵심 레퍼런스로 활용해 주세요.

**첫 번째 레퍼런스 — 레이아웃 및 정보 구조**
- 명확하게 구분되는 섹션
- 정돈된 그리드 시스템
- 넉넉한 여백
- 카드 기반의 정보 배치
- 직관적인 사용자 동선
- PC와 모바일에서 자연스럽게 변화하는 반응형 구조

**두 번째 레퍼런스 — 색감 및 인터랙션**
- 부드러운 라벤더 및 퍼플 그라데이션
- 밝고 세련된 배경
- 둥근 모서리의 카드와 버튼
- 은은한 그림자와 입체감
- 자연스럽게 떠 있는 듯한 UI 요소
- 섬세한 hover 효과와 부드러운 애니메이션

첫 번째 레퍼런스의 구조적 완성도를 유지하면서, 두 번째 레퍼런스의 시각적인 감성과 부드러움을 적용해 주세요.

## 3. 컬러 시스템

다음 색상을 기본 디자인 토큰으로 사용해 주세요.

- Primary: Deep Navy `#525A6B`
- Secondary: Soft Lavender `#9B8CFF`
- Gradient: `#9B8CFF` → `#C8B8FF`
- Main Background: Warm Ivory `#F8F5F1`
- Card Background: `#FFFFFF`
- Alternative Background: `#FAF9FF`
- Primary Text: `#292B35`
- Secondary Text: `#77758A`
- Point Gold: `#B9A06E`
- Soft Pink Accent: `#F5A6D6`

컬러 사용 원칙:
- 전체적으로 밝고 따뜻한 분위기를 유지합니다.
- 라벤더와 퍼플은 주요 버튼, 강조 카드, 그라데이션에 사용합니다.
- 네이비는 제목과 주요 정보에 활용합니다.
- 골드는 동양적인 분위기를 표현하는 작은 장식에만 제한적으로 사용합니다.
- 과도한 색상 사용이나 강렬한 네온 효과는 피합니다.

## 4. 타이포그래피

- 메인 제목: MaruBuri 또는 세련된 한글 Serif 계열
- 본문 및 UI: Pretendard 또는 SUIT
- 제목은 감성적이면서도 명확하게
- 본문은 모바일 가독성을 우선
- 주요 메시지는 큰 타이포그래피와 충분한 여백으로 강조
- 지나치게 작은 글씨는 사용하지 않습니다.

## 5. 전체 레이아웃 및 UI 스타일

- Mobile-first 반응형 디자인
- 데스크톱 최대 콘텐츠 너비 약 1200px
- 모바일 좌우 여백 20px 내외
- 8px 기반 간격 시스템
- 카드 모서리 반경 16~24px
- 버튼 모서리 반경 12~16px
- 은은하고 넓게 퍼지는 그림자
- 명확한 카드 계층 구조
- 섹션마다 충분한 상하 여백 확보
- 중요한 정보는 짧은 텍스트와 시각적 요소로 전달

전반적인 결과물이 흔한 AI 챗봇이나 기업용 SaaS 대시보드처럼 보이지 않도록 주의해 주세요.

## 6. 메인 랜딩페이지 구성

### Section 1. Hero

메인 카피:

**"당신의 사주를, 더 정확하고 더 다정하게."**

서브 카피:

"태어난 순간의 정보를 바탕으로, AI가 당신의 성향과 올해의 흐름을 이해하기 쉽게 풀어드려요."

주요 CTA:
- 내 사주 알아보기
- 서비스 살펴보기

Hero 영역에는 다음 요소를 배치합니다.
- 넓은 여백과 대형 타이포그래피
- 라벤더 그라데이션 배경 장식
- 실제 사주 분석 결과를 보여주는 스마트폰 목업
- 사주 요약 및 AI 질문 카드가 떠 있는 듯한 구성
- 동양적인 곡선이나 원형 장식을 최소한으로 활용

데스크톱에서는 좌측 텍스트, 우측 서비스 목업의 2단 구조를 사용합니다.

모바일에서는 텍스트와 CTA가 먼저 보이고, 아래에 서비스 목업이 표시되도록 구성합니다.

### Section 2. 서비스 핵심 장점

제목:

**"복잡한 사주를, 쉽고 편안하게."**

4개의 카드로 구성합니다.

1. 정확한 사주 계산
   - 생년월일시를 바탕으로 사주팔자와 오행을 체계적으로 계산합니다.

2. 자연스러운 AI 해석
   - 어려운 명리학 용어를 이해하기 쉬운 문장으로 설명합니다.

3. 나에게 맞는 질문
   - 궁금한 주제를 선택하고 AI에게 추가로 질문할 수 있습니다.

4. 한눈에 보는 결과
   - 나의 성향과 올해의 흐름을 보기 좋은 카드로 정리합니다.

데스크톱에서는 4열 그리드, 모바일에서는 2열 또는 1열로 배치합니다.

### Section 3. 서비스 이용 방법

제목:

**"세 단계로 만나는 나의 이야기"**

STEP 01. 생년월일시 입력  
STEP 02. 사주 계산 및 AI 해석  
STEP 03. 결과 확인과 추가 질문

단계별 아이콘과 연결선을 사용하되, 복잡하지 않게 구성합니다.

### Section 4. 사주 결과 미리보기

제목:

**"나를 이해하는 새로운 시선"**

실제 서비스 결과 화면을 카드 형태로 미리 보여줍니다.

포함할 카드:
- 나의 핵심 성향
- 사주 여덟 글자
- 오행 분포
- 올해의 운세
- 나를 위한 실천 조언

오행 분포는 가독성 높은 막대그래프 또는 도넛 차트로 표현합니다.

실제 사주 계산값은 임의로 확정하지 말고, 디자인 시안에는 예시 데이터임을 명시합니다.

### Section 5. AI 상담 경험

제목:

**"궁금한 이야기를 조금 더 나눠보세요."**

실제 AI 상담처럼 보이는 대화형 UI 미리보기를 구성합니다.

추천 질문 예시:
- 올해 취업운은 어떨까요?
- 저는 어떤 성향을 가지고 있나요?
- 연애할 때 어떤 모습인가요?
- 올해 어떤 변화에 주목하면 좋을까요?

질문 칩은 둥근 캡슐 형태로 제작하고, 선택하면 부드럽게 강조되도록 구성합니다.

### Section 6. 마지막 CTA

라벤더 그라데이션을 활용한 넓은 배너를 제작합니다.

메인 문구:

**"나를 알아가는 새로운 이야기, 지금 시작해 보세요."**

버튼:
"무료로 내 사주 알아보기"

과도한 광고 문구 없이 자연스럽게 서비스 이용을 유도합니다.

### Section 7. Footer

- 서비스 로고
- 서비스 소개
- 개인정보 처리방침
- 이용약관
- 문의
- 사주 해석은 자기이해를 위한 참고 자료라는 안내 문구

## 7. 핵심 서비스 화면

랜딩페이지뿐 아니라 다음 3개 화면도 같은 디자인 시스템으로 구성해 주세요.

### A. 사주 정보 입력 화면

입력 항목:
- 양력 / 음력 선택
- 음력 선택 시 평달 / 윤달
- 생년월일
- 출생 시간
- 태어난 시간 모름 옵션
- 성별
- 출생 지역(선택)
- 관심 주제

단계형 입력 폼을 사용하고, 모바일에서 조작하기 편리하도록 디자인합니다.

### B. 사주 분석 결과 화면

정보 표시 순서:
1. 핵심 성향 요약
2. 사주 여덟 글자
3. 오행 분포
4. 나의 강점과 보완점
5. 올해 운세
6. 실천 조언
7. AI에게 추가 질문하기

각 영역은 별도의 카드로 구분합니다.

한꺼번에 많은 정보를 보여주기보다 핵심 요약부터 자연스럽게 읽을 수 있도록 구성합니다.

결과 카드에는 공유하거나 이미지로 저장할 수 있는 UI를 포함해 주세요.

### C. AI 상담 화면

- 사용자 질문 입력 영역
- 추천 질문 칩
- AI 답변 카드
- 대화 흐름 유지
- 답변 생성 중 로딩 애니메이션
- 추가 질문 유도

일반적인 메신저 디자인보다는 따뜻하고 정돈된 개인 상담 공간처럼 표현해 주세요.

## 8. 인터랙션 및 애니메이션

다음 인터랙션을 적용합니다.

- 버튼 hover 시 미세한 상승과 색상 변화
- 카드 hover 시 부드러운 그림자 변화
- 스크롤 시 섹션의 자연스러운 등장
- 입력 단계 전환 시 부드러운 슬라이드 효과
- 추천 질문 선택 시 시각적 피드백
- AI 답변 생성 시 자연스러운 로딩 표시
- 모션 시간은 대체로 180~300ms
- 사용자가 애니메이션 감소를 설정한 경우 모션 최소화

과한 패럴랙스, 번쩍이는 효과, 불필요한 3D 애니메이션은 사용하지 않습니다.

## 9. 모바일 최적화

- 360~430px 너비에서도 가로 스크롤이 발생하지 않도록 구현
- 주요 버튼 높이 44~48px 이상
- 본문 기본 크기 약 16px
- 입력 화면은 터치 조작에 최적화
- 결과 화면은 세로 스크롤 중심
- PC와 모바일 모두 동일한 브랜드 경험 유지
- 모바일 화면에서 중요한 CTA가 쉽게 발견되도록 구성

## 10. 반드시 지켜야 할 사항

- 첨부 레퍼런스를 그대로 복제하지 말고 구조와 분위기만 참고합니다.
- 기존 사주 앱처럼 지나치게 무속적이거나 고전적인 분위기를 만들지 않습니다.
- 자극적인 운명 예언, 공포를 조성하는 표현은 사용하지 않습니다.
- 너무 화려한 보라색이나 네온 효과를 사용하지 않습니다.
- 실제 기능이 없는 버튼을 작동하는 것처럼 표현하지 않습니다.
- 개인정보 입력 화면은 신뢰감과 명확한 안내를 우선합니다.
- 아직 출시 범위에 포함되지 않은 궁합, 오늘의 운세, 대운 기능은 메인 기능처럼 표시하지 않습니다.
- 실제 제공되는 종합 사주 분석과 올해 운세를 중심으로 설계합니다.
- AI 해석은 확정적인 미래 예언이 아니라 자기이해를 돕는 참고 자료로 표현합니다.

## 11. 최종 결과물 목표

최종 디자인은 다음 인상을 전달해야 합니다.

**"전문적인 서비스처럼 신뢰할 수 있지만, 처음 방문한 사람도 편안하게 사용할 수 있는 감성적인 AI 사주 서비스."**

첫 번째 디자인 레퍼런스의 구조적인 랜딩페이지 구성과 두 번째 레퍼런스의 라벤더 기반 부드러운 색감, 둥근 UI, 세련된 인터랙션을 조화롭게 결합해 주세요.

랜딩페이지와 실제 서비스 화면이 하나의 일관된 디자인 시스템 안에서 연결되도록 제작해 주세요.
